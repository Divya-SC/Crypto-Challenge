# CR7 Token Investigation Dashboard

Final section-based GitHub Pages dashboard.

## Evidence placement

Images are placed inside the relevant dashboard sections:

- Jito screenshots → Jito Bundle section
- deBridge / Blockscan / Etherscan screenshots → Fund Flow section
- Etherscan USDC inflows + Beaverbuild state screenshots → Execution-Layer Routing section
- Token metadata details → Metadata / Official Campaign Link section
- Telegram / X / BubbleMaps screenshots → Social Promotion section
- Account info screenshots → Identity Reuse section

## GitHub Pages setup

1. Upload all files to your repository.
2. Go to **Settings → Pages**.
3. Select:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
4. Save.

Your site will be:

`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`
